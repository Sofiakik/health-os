# Health OS

A health tracking web app built with Next.js and Supabase, deployed on Vercel.

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Documentation

- **Product vision & roadmap:** `docs/product/`
- **Architecture decisions:** `docs/decisions/`
- **Research notes:** `docs/research/`
- **AI agent instructions:** `CLAUDE.md` and `AGENTS.md`

## Stack

- Next.js (App Router) + TypeScript
- Supabase (database)
- Vercel (deployment)
