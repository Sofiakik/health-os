# Advanced Jobs To Be Done (AJTBD) — Methodology Reference

This folder contains the core concepts and practical guides from the Advanced Jobs To Be Done methodology (by Ivan Zamesin). It is used to guide product research, segmentation decisions, and hypothesis testing for Health OS as we explore building a commercial product.

## Contents

| File | Description |
|------|-------------|
| `01-foundations.md` | What JTBD is, job hierarchy (Big/Small/Core Job), key definitions |
| `02-jobs-graph.md` | How jobs connect and relate, types and properties of jobs |
| `03-segmentation.md` | How to choose which customers and which jobs to focus on; segment profitability; focus segment; niche growth algorithm |
| `04-research-principles.md` | Interview principles, emotional contact, common mistakes |
| `05-interview-guide-b2c.md` | Full B2C interview guide with question scripts (v3.3) |
| `06-interview-guide-b2b.md` | Full B2B interview guide with question scripts (v3.3) |
| `07-critical-job-chains.md` | Job chains (B2C/B2B/B2B2C), "follow the money", finding bottlenecks and orphan jobs |
| `08-product-value.md` | Value = deviation from expectation; baseline quality; 13 mechanics of creating value; value growth algorithm |
| `sources.md` | All source materials and PDFs |

## How to use this with Claude

When working on product decisions, ask Claude:

- "Read docs/methodology/jtbd/ before answering"
- "Based on our JTBD methodology, how should I approach finding my first users?"
- "Help me write a JTBD job description for [user type]"
- "Based on the interview guide in docs/methodology/jtbd/, what questions should I ask tomorrow?"

## The core question this methodology helps answer

Not "what features should I build?" but "what job is someone trying to get done, and am I the best solution for it?"
